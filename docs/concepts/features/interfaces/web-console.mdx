The web console is a single entry point for the web UIs built into the ClickHouse server. It is served from any ClickHouse HTTP port at the `/console` path, for example `http://localhost:8123/console`.

Sign in once with a ClickHouse user, and work in one window: the SQL Console, dashboards, and diagnostics, and the administration of users, roles, data access policies, backups, clusters, and identity providers. Every query and every administrative action runs with the credentials of the signed-in user, and the server authorizes each one.

The documentation of the console is in its own section, [Web Console](/products/web-console/overview).
